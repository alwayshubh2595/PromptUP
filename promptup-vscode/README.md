# PromptUp — VS Code Extension

Enhance coding prompts in-place for AI assistants (Claude Code, GitHub Copilot, Codex) with `Ctrl+Shift+E`.

Part of the [PromptUp](../README.md) project.

## Setup

1. Open this folder in VS Code and press **F5** to launch the Extension Development Host
2. `Ctrl+Shift+P` → **PromptUp: Set API Key** → paste your Anthropic key

## Shortcuts

| Context | Shortcut | Action |
|---------|----------|--------|
| Text editor | `Ctrl+Shift+E` | Enhance selected text (or full file) |
| Terminal | `Ctrl+Shift+E` | Open prompt input → enhance → send to terminal |

## Modes

`Default` · `Debug` · `Generate` · `Refactor` · `Review` · `Tests` · `Explain` · `Token-Save` · `Expert` · `Custom`

See the [root README](../README.md) for full mode descriptions.
